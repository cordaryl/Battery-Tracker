# AI Assistant Rules for BatteryCycle Track

When working on this project, the AI must strictly adhere to the following rules:

## Versioning and Changelogs
1. **Daily Version Point Update:** Whenever there is a new day of updates or code changes, you MUST increment the version point of the application (e.g., from `v1.17.0` to `v1.17.1`).
2. **Frequency Limit:** Do not perform version updates more than once a day unless it is considered a major update. 
3. **Changelog Requirement:** You MUST *always* update the changelog for any changes made, even if the version number is not incremented. The changes should be logged accurately with the corresponding date. (Note: The changelog and version number are typically located within the `index.html` file in the `APP_VERSION` and `CHANGELOG` constants).
